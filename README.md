# Giz

A student planner that warns you **before** the deadline, not on it.

Register your class schedule once, then create work due "next math class" instead of
hunting for the date on a calendar. Choose how many days ahead it warns you, how many
times, and whether it nags like an alarm.

iOS first (Expo + React Native, with Swift where iOS is better at it), Android next.
